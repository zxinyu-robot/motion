## 1. 申请目标与边界

### 1.1 一句话发明点

**【设计决策】** 提供一种面向视觉-语言导航/动作模型的机器人空间数据序列化与端边协同方法：在线建图端输出**版本化哈希增量体素事务**，按**运动与几何变化联合条件**提取关键时空切片，序列化为可解码的轻量 **Spatial Token**，卸载至离线语义推理端；语义端返回粗粒度导航目标，由边端本地规划器与外部安全接口执行，形成可追溯闭环。

### 1.2 主张 / 不主张

| 主张【设计决策】 | 不主张 / 不绑定 |
|---|---|
| 哈希结构增量体素的版本化事务与差分序列化 | 具体 SLAM 滤波器内部结构（如某开源 LIO） |
| 运动条件与几何变化条件联合的关键切片触发 | 某一固定阈值数值作为唯一实施方式 |
| Token 契约与传输载荷分层；模型输入由 Adapter 派生 | 某一具体 VLN/VLA 权重或训练方法 |
| 语义端输出粗粒度目标，不直接输出底层速度指令 | 某一厂商固件避障算法为自有 IP |
| 边端在语义链路失效时可独立安全降级 | AsyncShield 的 CMDP / PPO-Lagrangian 等他人方法 |
| 可替换 Producer / 规划器 / Adapter | 6G 专用物理层、异构能力协商完整方案（后续） |

### 1.3 与工程主链对应

| 工程 Gate | 对专利内容的支撑 |
|---|---|
| P0-A 增量事务可用 | 说明书实施例：帧级 ADD/UPDATE/EVICT/RESET、可重放 |
| P0-B TokenSequence + 干净网络 | 编解码、版本连续、载荷形态实施例 |
| P0-C 世界动作模型闭环 | 端边协同控制闭环实施例；任务成功证据 |
| P0-D WeakNet | 有益效果中的弱网/带宽/恢复主张【待补充实测】后写入对比数据 |

**【设计决策】** 申请文本可先按方案交底；对比实验与“显著优于基线”的表述，必须等对应 Gate 有 measured 证据后再写入答复或补交材料。

## 2. 技术问题（交底书第 1 块）

现有机器人语义导航/操作链路中，至少存在三类工程断层：

1. **数据接口断层**：在线 SLAM 通常输出位姿与稠密点云/网格，离线 VLN/VLA 侧难以直接、稳定地消费海量几何更新，常需重复体素化或全量重传。  
2. **时标与算力断层**：语义推理与网络时延显著慢于本地避障与轨迹控制；若将大模型置于边端，会挤占安全与规划资源。  
3. **闭环与证据断层**：语义目标、空间版本、执行终态缺乏统一关联；弱网或断连时难以区分通信失败、语义失败与运动失败，也无法安全降级。

现有公开方案多分别解决“更好的 SLAM”“更大的 VLA”或“通用 RPC 调度”，缺少把**增量空间状态**组织为**可版本化、可差分、可卸载、可回传执行**的中间层。

## 3. 技术方案总览（交底书第 2 块）

### 3.1 方法步骤（上位概括）

```text
S1 在线定位建图，生成位姿流与哈希结构增量体素状态
S2 按帧或按事件聚合为版本化体素事务（至少区分新增、更新、缓存淘汰/会话重置）
S3 以运动变化条件与几何变化条件联合判定是否形成关键时空切片
S4 对关键切片提取：位姿、可选视觉观测、仅变化体素条目（键、几何中心、统计特征等）
S5 编码为 Spatial Token / TokenSequence，经通信链路发送至离线语义推理端
S6 离线端解码后，经可替换 Adapter 形成模型输入，输出粗粒度导航目标或动作组
S7 边端关联目标与来源空间版本/时间戳，交本地规划器执行；底层速度指令不由语义模型直接发出
S8 边端通过外部安全接口进行碰撞/急停兜底；语义链路失效时本地规划与安全链可独立运行
S9 回传执行终态、失败原因及关联空间版本，形成可追溯闭环
```

### 3.2 四层对象分层（防止独权写窄）

```text
体素事务（Producer 事实）
  → Spatial Token / TokenSequence（稳定语义契约）
    → 网络载荷（具体序列化/分片实现）
      → VLN/VLA 输入（Adapter 派生，可替换）
```

**【设计决策】** 独权钉在前两层及 S3/S6/S7/S8 的组织方式；具体 Protobuf 字段名、某一投影方式、某一传输库仅作从属或实施例。

### 3.3 系统与装置

- **边端装置**：传感器接入、在线建图模块、事务聚合模块、关键切片判定模块、Token 编码与发送模块、目标接收与本地规划模块、安全接口模块、结果回传模块。  
- **离线推理装置**：Token 解码模块、Adapter 模块、VLN/VLA 推理模块、目标下发模块。  
- **系统**：边端装置 + 通信链路 + 离线推理装置。

## 5. 权利要求骨架（草案，供代理人改写）

> 以下为内容方向，非法条定稿。阈值、字段名、库名不进独权。

### 5.1 独立权利要求方向

**独权 A（方法）**  
一种面向视觉-语言机器人模型的空间数据序列化与端边协同方法，其特征在于包括：  
生成位姿与哈希结构增量体素；形成版本化体素事务；按运动条件与几何变化条件联合触发关键切片；提取变化体素条目并编码为 Spatial Token 发送至离线语义端；接收粗粒度导航目标并关联空间版本后交本地规划执行；语义模型不直接输出底层速度指令；边端在语义链路异常时依赖本地安全接口继续保障安全；回传终态与关联版本。

**独权 B（系统）**  
包括边端装置与离线推理装置，实现独权 A 所述步骤。

**独权 C（装置）**  
边端装置：事务聚合、联合触发、Token 编码发送、目标执行与安全兜底、结果回传。

### 5.2 从属权利要求方向

1. 体素事务事件类型至少包括新增、更新、缓存淘汰与会话重置，且缓存淘汰不解释为现实障碍消失。  
2. 关键切片还可由任务指令变更或超时兜底触发。  
3. Token 与网络载荷分离；载荷可采用 Protobuf/FlatBuffers 等。  
4. Adapter 将 Token 投影为多视图图像式输入，或稀疏体素编码器输入。  
5. 下行目标为点/朝向偏好/动作组中的至少一种。  
6. 本地规划器可替换；替换后保持目标接口与安全边界。  
7. 目标超过时滞阈值或空间版本不连续时拒绝执行或请求重规划。  
8. 多机场景下各边端 Token 按版本合并为共享空间状态后再做语义调度（分案/后续）。

## 6. 说明书实施例提纲（不绑死产品名）

### 实施例 1：单机端边语义导航（对应 P0-A～P0-C）

1. 机载激光/IMU 在线建图，输出哈希增量体素与位姿；  
2. 帧级聚合事务并记录；  
3. 运动或几何变化触发关键切片；  
4. 编码发送至机旁/边缘计算节点；  
5. 节点上 VLN 输出粗目标；  
6. 机载 2D/局部规划执行，安全接口兜底；  
7. 回传到达/超时/版本不连续等终态。

### 实施例 2：干净网络到弱网对照（对应 P0-D）

在实施例 1 闭环成立后，分别注入限带宽、时延、抖动、丢包、短时断连，记录 Token 新鲜度、过期比例、任务成功与安全触发；用于说明书有益效果与实验数据【待补充实测】。

### 实施例 3：可替换前端/模型

同一 Token 契约下更换在线建图前端或更换离线 VLN 模型，验证中间层不依赖特定引擎/模型——支撑“协议不变量”叙述。

### 实施例中可出现、但独权宜上位的示例参数

运动位移/转角阈值、体素变化计数阈值、超时兜底周期、载荷封装格式等，均写为**可选实施方式**，避免把实验调参写成唯一保护范围。
