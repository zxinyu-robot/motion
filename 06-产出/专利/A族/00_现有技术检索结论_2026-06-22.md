## 二、关键现有技术（按威胁度排序）

### 🔴 威胁最大：刘华颖《空地异构机器人协同系统》（2026，airr.2026.152042）

学术综述/方案论文，已公开以下与本项目高度重叠的内容：

- 统一硬件抽象层（HAL）屏蔽异构差异，实现"即插即用"接入；
- 容器化驱动 + **安全接入代理**（运行于本体或邻近边缘节点）——等同"挂算力盒子 + 外挂代理"；
- 机器人启动后代理主动上报 **实时能力集（载荷/传感器类型）+ 状态**——等同"能力声明 + 动态注册"；
- 某感知失效时利用异构单元进行 **补偿感知**——接近"缺失补偿"（但限于感知冗余）。

**与本项目的关键差异（必须在交底书中据此划界）**：
1. 它的能力声明服务于 **任务分配/调度（谁去投标干活）**；本项目服务于 **空间建模一致性**。
2. 它的"补偿"是 **感知冗余补偿**；本项目是 **缺失建模环节（子图/语义/回环/坐标对齐）在边缘侧补齐**。
3. 它是概念性方案论述，未到"能力等级→建模链路自配置/补偿"的具体方法机制层。
4. 它不以"建模一致性"为命题。

→ 结论：**"用代理上报能力集做即插即用接入"已是现有技术**，本项目接入发明点必须收窄到"能力声明驱动建模链路（补偿 + 自配置）以保障一致性"。

### 🟠 空地协同建图（学界）
- **SlideSLAM**（arXiv 2406.17249）：异构空地团队、对象级 metric-semantic 地图、语义 place recognition 做跨视角 inter-robot loop closure、去中心化、间歇通信下一致建图。**最接近核心命题**，但假设各机器人能跑完整语义 SLAM（能力对等）。
- **Kimera-Multi**（2106.14386）：分布式 dense metric-semantic SLAM、鲁棒 PGO、局部 mesh 形变改善全局一致。
- **D²SLAM**（2211.01538）：近场/远场、runtime 合并不同机器人参考系、全局一致。
- **COVINS**（2108.05756）：中心化 server map manager 控制地图访问以保证全局一致。
- **空地跨域协同 SLAM**（MDPI 9/7/504）：PCM 异常检测、UAV+UGV 融合成统一全局地图。

### 🟠 空地协同建图（专利）
- **CN116989772B**：空地多模态多智能体协同定位与建图，UAV 检测视觉标志物获相对位姿，空地视角地图融合 + 回环，输出全局一致地图。
- **CN109579843A**（项目已引）、**CN113674409A**、**CN111300372B**、CN114485619A。

### 🟡 跨视角对齐 / 接入适配（相关但非正面）
- VGA（CVPR2026）、TransLocNet、L2RSI、Semantic Crossview Localization：跨视角/BEV 对齐算法。
- **CN118642754A**：机器人 OS 跨平台开发架构——"模块转换器"做 ROS 间**代码移植**（标准化 API 封装），目的是同套代码跨平台运行。属"开发期接口适配"，与本项目"运行期能力声明 + 建模补偿"方向不同，可作接口适配类现有技术引用划界。

## 二之二、第二轮验证检索（重大发现，2026-06-22）

针对收窄点"能力参差 × 建模一致性"做验证检索，结果**不利**：

### 🔴🔴 HAMMER（arXiv 2501.14147，2025）—— 对接入发明点几乎正面命中
- 明确"operate as a **black-box platform**"，把本体板载定位算法当**黑盒**；
- 只取"**camera poses and images**"作为输入，**不需访问内部定位算法**（与本项目"最低接入门槛=位姿+图像"重合）；
- 明确指出"需要访问底层信息（位姿图/稀疏图）的对齐方法在**闭源软件**下会失败"——即直击"厂商不开源"痛点；
- 支持异构、异步、不同传感器与不同 SLAM 算法，服务端对齐到全局 frame 并实时训练 metric-semantic 3DGS 地图，新机加入只对齐一次。
- **结论**：本项目"黑盒 + 位姿/图像非侵入 + 异构一致建图"不再具新颖性。

**与 HAMMER 仍存的差异（可能的窄缝）**：
1. HAMMER 把所有平台**一刀切降到"位姿+图像"最低公分母**；本项目主张**按能力等级差异化处理**（白盒用全量原始数据、黑盒补齐缺失环节），不浪费白盒能力。
2. HAMMER 产出单一 3DGS 辐射场地图；本项目维护**结构化多层 World Model**（几何+语义+任务+通信+动态+时序）并做**任务级多源冲突裁决**。
3. HAMMER 不涉及 GPS 拒止下空地视角互补、弱网语义优先传输。

### 🟠 其它相关
- **Towards Decentralized Heterogeneous Multi-Robot SLAM**（2306.04570）：让用不同估计算法的机器人协同（algorithm-agnostic），靠 factor graph 共享。
- **CN120353230B**：异构多机器人自主协同探索 + 自适应动态任务分配（任务分配，非建模能力补偿）。
- **CN117213470B**：多机碎片地图聚合、分层重定位、重叠度更新、一致性全局地图。
- 综述提及 **DC-Ada**：基于奖励的去中心化适配，把异构观测映射到固定接口。

→ **总判断**：原以为最有空间的"非侵入接入/能力适配"已被 2025–2026 工作大面积覆盖。剩余空间只在更窄的结合点（差异化能力利用、结构化多层 World Model 任务级一致性、特定整体组合），且均需进一步核验，单独成强独权的把握下降。

## 二之三、HAMMER 精读：做了什么 / 明确没做什么（区别特征比对）

| 维度 | HAMMER（2501.14147, 2025）做了 | HAMMER 明确没做（=本项目活口） |
|---|---|---|
| 接入 | 黑盒本体，仅用位姿+图像/深度，一次性对齐 | "**无位姿设备用不了**""**不支持纯RGB**"——对能力**一刀切硬门槛**，无"缺失能力补齐" |
| 地图 | 单一 metric-semantic **3DGS 辐射场** | **非结构化多层 World Model**：无任务层/通信层/动态对象层、无时效过期、无显式**多源冲突裁决规则**（靠优化器硬调和） |
| 通信 | 需 **30–35 Mbps**、高端 WiFi | **完全不碰弱网/带宽受限/语义优先分级传输** |
| GPS拒止 | 被动等视觉重叠，假设≥1台给 metric 位姿 | 无 **GPS 拒止下空地视角主动互补**（空中俯视当锚点拉地面漂移）策略 |
| 架构 | 中心化单 GPU 服务器 | 无云边端、无自组网、无反向调度 |

**结论**：HAMMER 锁死了"黑盒+位姿图像非侵入接入+异构一致建图"这一层；但它是一篇**理想网络/理想数据假设下的建图算法论文**，凡是"系统侧/通信侧/数据管理侧"的真实工程机制，它都跳过了。

## 三、收窄后真正可主张的发明点（按把握度排序）

> 重心从"接入/建图算法"移到 HAMMER 这类论文**不碰的系统/数据管理侧**——这恰好回到项目最初的直觉："发明点在管理方法、数据输入输出流水线"。

1. **【最稳·04】弱网/带宽受限下的语义优先分级传输与可信融合**：按任务语义价值分级回传、数据链路层差异化可靠、边缘端抗幻觉可信融合。HAMMER 需 30Mbps 且完全不做弱网——这是干净空白。
2. **【次稳·03】结构化多层 World Model 的多源冲突裁决 + 时效/置信度管理 + 增量 Delta**：几何+语义+任务+通信+动态+时序的结构化世界状态与显式冲突裁决规则。与 HAMMER（单层辐射场）、Kimera-Multi/COVINS（metric-semantic 一致性，无任务/通信层）划界。
3. **【辅助】能力差异化接入与缺失补偿**：突破 HAMMER"无位姿即不可用"的硬门槛——黑盒缺位姿/深度/语义时在边缘侧补齐，白盒用全量，按能力等级差异化（而非一刀切降级）。
4. **【辅助】GPS 拒止下空地视角主动互补**：主动用空中俯视为地面提供全局锚点对抗漂移（区别于 HAMMER 被动等重叠）。

**已放弃（红海/被占，不再作新颖点）**：空地协同一致建图整体、跨视角对齐算法、黑盒位姿图像非侵入接入、能力声明即插即用。

## 四、对四篇布局的影响

- **新增独立发明点（接入篇）**：收窄为"能力声明驱动的建模补偿与职责分配"，而非泛化的"非侵入接入"。
- **03（核心）**：World Model 一致性裁决要强调"跨异构平面 + 能力分级来源的可信度加权"，以区别于 COVINS/Kimera-Multi 的同构一致性。
- **02/04**：作为建模一致性所需信息（几何对齐量、关键约束）的获取与弱网传输手段，定位不变。
- **01**：承载上述流程编排。
