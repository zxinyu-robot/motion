# 多机器人协同 —— 强化学习支线计划

> **定位**：个人/学术支线，**不纳入**主规划 P0 产品 WBS 与对外交付里程碑。  
> **与主线关系**：复用主线的 KeyFrame/VoxelDiff 协议、弱网 Benchmark 与 Gazebo/Go2 仿真环境；RL 负责「谁做什么、何时共享什么」，**不替代** SLAM 前端、通信中间件与安全兜底。  
> **背景**：本科通信 + 两年机器人工程；当前从事异构机器人协同 SLAM 框架平台，核心痛点是传统 RPC 顶层调度下机器人难以形成有效协同（任务分配、主动探索、地图信息共享）。  
> **对齐方向**：陈涛（边缘 AI Infra）、余翀（模型压缩 + 群体协同 / MAGIC Lab）。  
> **更新**：2026-07-15

---

## 1. 一句话定位

在弱网、异构多机器人协同 SLAM 框架中，用**通信感知的多智能体强化学习**解决任务分配、主动探索与地图增量调度，使策略在带宽/延迟/丢包约束下优于固定 RPC 与周期通信规则。

## 3. 问题形式化

### 3.1 建模：带通信预算的多智能体 POMDP

- **智能体**：N 台机器人 + 可选边缘网关（集中 critic 训练时可视为全局观测源）。
- **局部观测** o_i：
  - 自身位姿、定位协方差/不确定度
  - 局部地图摘要、未探索 frontier
  - 当前子任务状态、剩余电量/算力（异构时）
  - 邻居最近状态（若可达）
  - **通信状态**：带宽上限、RTT、丢包率、断连时长、待发队列长度
  - 待发 KeyFrame / SpatialChunk / VoxelDiff 的大小与估计信息增益
- **动作** a_i（离散或分层）：
  1. 子任务 / frontier / coarse waypoint 选择
  2. 是否通信、通信对象（网关 / 指定邻居）
  3. 发送优先级（关键帧 vs 体素 diff vs 任务状态）
- **奖励** R（示意，权重需消融）：  
R = \alpha R_{\text{task}} + \beta R_{\text{map}} + \gamma R_{\text{loop}} - \lambda B_{\text{bytes}} - \mu T_{\text{delay}} - \eta P_{\text{collide/deadlock}}
- **安全**：碰撞、越界、不可达 waypoint 由传统避障 + safety shield 拦截，**不**仅靠负奖励学习。

### 3.2 核心对比基线


| 基线  | 描述                      |
| --- | ----------------------- |
| B0  | 顶层 RPC：中心调度任务，无机器人间主动协同 |
| B1  | 固定周期广播地图/状态             |
| B2  | 事件触发（仅位姿变化/回环候选超阈值才通信）  |
| B3  | 独立 PPO（无 CTDE，无通信动作）    |
| B4  | **MAPPO + 通信动作**（主方法候选） |

## 5. 算法路线

按阶段递进，**禁止**首版同时堆叠 MAPPO + GNN + 世界模型 + 大模型。


| 阶段  | 算法                     | 目的                |
| --- | ---------------------- | ----------------- |
| S0  | 规则 + 贪心                | 可解释基线，验证环境与奖励是否合理 |
| S1  | **MAPPO**（CTDE）        | 主方法；连续/离散动作均可     |
| S2  | QMIX                   | 全离散动作时的价值分解对照     |
| S3  | GNN + MAPPO            | 智能体数量与拓扑变化时扩展     |
| S4  | 约束 RL / Lagrangian PPO | 显式带宽、碰撞、超时约束      |


**训练范式**：集中训练、分散执行（CTDE）；仿真环境需可注入延迟、丢包、断连。

## 7. 实验指标（对齐 P0 Benchmark）

引用 `40-验证/P0-Benchmark-模板.md`，本支线额外强调：


| 指标                    | 定义要点                         | 工具/来源                        |
| --------------------- | ---------------------------- | ---------------------------- |
| 任务成功率 SR              | 全体子任务完成且满足 Arrival 条件        | 仿真计数                         |
| SPL                   | 与 VLN 场景一致的路径长度加权成功率         | 标准公式                         |
| 每成功任务传输量 (MB/success) | 总发送字节 / 成功任务数                | 通信模块日志                       |
| 弱网丢包下 SR              | 固定丢包率扫参                      | 网络仿真层                        |
| 断网恢复时间 (s)            | 断连 → 协同恢复可规划                 | 时间戳日志                        |
| 重复探索率                 | 多机覆盖同一 frontier 的比例          | 地图覆盖统计                       |
| 跨机回环触发次数              | 协同 SLAM 有效回环                 | Swarm-SLAM / 仿真 ground truth |
| 训练样本效率                | 达到 B2 性能所需 environment steps | RL 训练 log                    |
