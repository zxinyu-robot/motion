# 05-知识沉淀（Knowledge）

存放**可复用的技术能力卡片**，不是「某篇论文笔记」的副本。

## 命名

```
05-知识沉淀/
├── slam/
├── communication/    ← 传输栈、MapAPI 等数据面参考
├── deployment/
├── eval/
├── process/          ← 协作/Harness 等流程能力
├── planning/
└── world-model/

文件：CAP-<主题缩写>-<序号>.md
```

## 能力卡模板

```markdown
# 能力标题

## 结论
……

---

## 文档元数据

| 字段 | 值 |
|------|-----|
| id | CAP-XXX-001 |
| type | capability |
| sources | 论文/工程/实验引用 |
| applies_to | Go2 / 网关 / VLA / … |
| evidence_level | proposal / measured |
| updated | YYYY-MM-DD |
```

## 结论（1–3 句）
## 适用条件
## 不适用
## 关联架构模块
## 关联任务/专利/论文 ID
```
